# Köy Hayatı 3D

Tarayıcıda çalışan birinci şahıs köy yaşamı prototipi.

## Çalıştırma
Bu klasörü statik site olarak yayınlayın. Giriş dosyası `index.html`.

## Kontroller
- WASD: yürü / araç sür
- Fare: etrafa bak
- Shift: koş
- E: yakındaki araca bin / araçtan in
- ESC: fareyi serbest bırak

Three.js CDN üzerinden yüklenir. İlk prototipte ev, garaj, ağaçlar, köy çevresi ve temel geometrilerle modellenmiş traktör, greyder, remorklu kamyon ve Tempra bulunur.
